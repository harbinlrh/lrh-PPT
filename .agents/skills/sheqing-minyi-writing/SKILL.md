# 社情民意信息撰写

把可核验的一线情况写成供决策研判的中文信息。成稿围绕一个公共问题，写明问题表现、影响范围和成因，提出能够落实的对策。完整稿件的问题分析必须同时使用经核验的权威数据和真实案例，并说明证据支持到哪一步。

## 确定报送层级和问题

- 从原稿、调研记录、收稿要求和政策线索入手，确认主体、场景、时间和适用范围。渠道未定时，先按材料实际覆盖范围写通用送审稿。地方稿着眼本级可解决的堵点。全国层面的判断需要跨地区材料或全国适用的制度依据。
- 从政策目标、执行环节和现有差距中确定切口。把题目写到具体对象和治理环节。用户明确要求以某一地区、品类或事件作为案例时，标题、帽段和建议围绕上位议题展开，让案例服务于相应论点。
- 只做用户要求的环节。题目和主要事实清楚时直接写稿。若只有方向或未经证实的消息，先补查权威资料。仍不够支撑结论时，写出已有依据的段落和待补证的问题，明确稿件尚处于调研或待核阶段。

## 问题分析必须有可核实的数据和案例

1. **追到原始发布。** 数据优先取自有统计职责的政府部门、权威统计公报、正式调查和具备相应资质的科研机构原始报告。案例优先取自主管部门、地方政府的通报、正式答复、监管公告、司法文书或权威研究机构公开的调查记录。按主张选择有相应职责或研究能力的来源。只在转载中发现材料时，尽量找到原文或正式通报全文。搜索摘要、商业宣传、聊天截图和模型输出可提供检索线索，不能单独承担关键论证。
2. **逐项校验。** 每项拟引用的数字和案例都打开原文，定位到原表、段落、附件或正式通报，记录发布者、资料名称、日期和可回查链接或文件位置，作为工作核验记录。数据核对数值、单位、分母、样本、地域、统计期和适用口径。自己计算的结果要复算并讲清计算基数，政策目标、预测值与实际测算分别表述。案例核对时间、地点、对象、过程与结论，区分媒体反映、启动调查、检验结果和最终处置。对关键且有争议的事实，优先找独立的一手来源交叉验证。
3. **评估证据能说明什么。** 对每条关键判断说明数字或案例支持的是个别现象、普遍程度、流程堵点、成因还是试点可行性。全国平均值不能证明某个县的水平，单个案例不能推出全国发生率或因果结论。核对政策时查原文、效力、适用地区、对象和例外。遇到来源冲突，先查统计口径、时间、版本或案件阶段。无法调和时，改用已核实的部分、收窄结论，或在稿外提示待核。
4. **让数据和案例承担不同任务。** 用权威数据交代规模、变化、覆盖率或差异，用权威案例显示问题在哪个环节发生、有哪些可观察的后果或可行做法。两者放进对应的问题段，接着写自己的分析，解释已知事实如何支持判断。没有足够证据的段落可并入其他问题，或作为明确标注的风险和待核假设。严禁编造、补造、移花接木或夸大数据、案例、机构、报告、访谈、引语、出处和采用记录。

## 写成可送审的正文

按收稿渠道调整字数和格式。未给定模板时，专题稿可参考约2000—2500字，问题分析是正文重点。

- **标题。** 直接点明具体对象和主要矛盾或施策抓手。少用泛化套式，报送渠道规定固定格式时按规定处理。
- **反映人信息。** 在标题下、帽段前列经用户确认且可报送的姓名和身份。未提供时提示待补，保留原稿已有署名。
- **帽段。** 简要交代核心情境、治理价值和现实落差，尽早提出主要问题。独立摘要按渠道指定位置放置，简述问题、重要性、关键矛盾和建议，数字及结论与正文一致。
- **正文标题编号。** 每篇完整送审稿都列出一级、二级标题。一级标题用中文数字加顿号，通常写为“一、主要问题与成因”“二、对策建议”。二级标题用全角括号加中文数字，如“（一）”“（二）”“（三）”，在每个一级标题下从“（一）”重新编号。一级、二级标题各自独立成行，编号后写明具体问题或措施，另起一段展开。文稿总标题、署名、摘要和帽段不纳入正文标题编号。
- **主要问题与成因。** 每个小标题说明一个具体问题。用已核验数据或案例支撑段落，再解释影响和成因。重要数字、案例和政策依据出现时，直接用完整句子交代权威机构和资料原名，必要时写出发布年月、统计期和所处阶段。例如“据〔统计部门〕发布的《〔报告名称〕》，〔年份及统计对象〕……”。模板中的方括号仅示写法，成稿一律换成经核实的信息。采用叙述式正文归属，成稿中省去引文编号、脚注、文末参考文献和链接清单。来源链接或文件位置保留在内部核验记录，用户另有明确要求时可单独提供。
- **对策建议。** 逐条回应已经分析的成因，写清牵头主体、办理动作、实施条件和可观察的效果。涉及资金、执法、数据共享和企业义务时核对权责及适用条件。先行试点时交代对象、边界和评估办法。

## 交付前复核

- **政治关。** 核对正式表述和议题层级，用客观措辞说明公共治理价值。
- **政策关。** 核对政策版本、条款、适用主体与现行措施，检查建议补上了哪个明确缺口。
- **事实关。** 按定稿逐项复查所有关键数据与案例，确认正文写出了发布机构和具体出处，统计期、单位、对象、状态均与原件相符。剔除无法核验的材料，检查摘要是否比正文作了更强判断。
- **内容关。** 检查论点、证据、成因和建议能否相互对应。评估来源权威性、统计代表性与结论边界，避免把政策文本本身当成现实问题已发生的证明。
- **文字关。** 检查标题、署名、帽段和摘要，逐节核对一级和二级标题是否独立成行、按规定编号且每节从“（一）”起排。删除空泛背景、情绪化定性、重复例证和工作成绩罗列。

交付正文与独立摘要。若关键问题仍待核实，另在交付说明中列出影响最大的核验缺口和所需材料。用户只要求审稿时，优先指出未获证据支持的判断，并给出可直接采用的改写文字。
